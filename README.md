# Mateo Herrera Seguros · mateoherrera.com.co

Sitio web público + portal administrativo (en `/#admin`).

- `index.html`: el sitio completo y el portal, en un solo archivo.
- `vercel.json`: configuración de Vercel.

El portal guarda los datos en Supabase (proyecto `ppzegmemytxcfallivez`). Cada asesor entra con su cédula y su contraseña.
No subas a este repositorio bases de datos (.xlsx, .csv) ni archivos .sql: todo lo que está aquí queda público en la web.
